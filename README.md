# DeepSeek Music Persona

给正在 DSH 里工作的 DeepSeek 一副耳机。

这是一个面向 DSH 的音乐人格插件：从用户近期常听的音乐建立初始音乐环境，让 Agent 在本地逐渐形成自己的偏好，并在不打断工作的前提下自主决定是否听歌、听什么歌。QQ 音乐和网易云音乐是 v0.1 的音乐来源。

项目处于开发准备阶段，当前先锁定产品边界和技术验证顺序。完整范围、架构草案、里程碑和验收条件见[项目规划](docs/PROJECT_PLAN.md)。

## v0.1 原则

- 音乐行为不能阻塞 DSH 工作。
- 日常选歌、播放、历史和偏好更新在本地完成，不额外调用 LLM。
- Agent 的音乐人格与用户音乐环境分开保存。
- 用户的明确播放命令和限制优先于 Agent 的自主选择。
- 音乐核心与桌面窗口分离；隐藏或关闭窗口不停止音乐核心。

## 当前状态

尚未开始实现。第一阶段先验证 DSH 事件接入、两个平台的登录/播放能力、近期音乐数据获取与桌面悬浮窗技术路径。
