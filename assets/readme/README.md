# 仓库首页素材

- `hero.svg`：本项目绘制，1200 × 340，使用播放器的冷灰 / 蓝色配色，展示「参考歌曲 → 网易云找歌 → 模型挑歌 → 大肥鱼听歌」；MIT。流程同时保留在 README 正文中，便于窄屏和图片不可用时阅读。
- `panel.png`、`panel-dark.png`：2026-10-07 从 N22 `src/ui/dsh-client.js` 的隔离 UI 预览截取，对应 beta.2。使用真实的 720px 单列布局，取景从标题到歌单末尾，省略后续设置区域，避免两列高度不一致产生大片留白；不修改客户端布局或控件。以 1.5 倍像素密度导出 1080 × 1242 的浅深色 PNG。歌曲、统计和模型均为模拟数据；beta.1 仍是旧版界面。
