- `hero.svg`：本项目绘制，1200 × 260；沿用播放器的冷灰 / 蓝色和耳机标记，缩短头图并放大名称。流程保留在 README 正文中；MIT。
- `panel.png`、`panel-dark.png`：2026-10-13 从 beta.3 当前客户端的隔离预览重新截取，运行实现为 `50613ed`，渲染基线为 `fac83b9`。900px 容器，取景含播放器、歌单、听歌控制、管理分区和页脚；900 × 958 PNG，显示可用的“换一批”，不再展示历史冷却倒计时。
- `panel-narrow.png`、`panel-narrow-dark.png`：同一客户端和模拟状态的 360px 视口，从页头到歌单末尾，排除浏览器滚动条；344 × 821 PNG。后续设置未收入截图，仍可在客户端滚动查看。

README 使用 GitHub 支持的 `picture/source`，按宽度与浅深色偏好选择截图。所有图片都是模拟歌曲、账号状态和模型数据，不能证明生产账号、真实模型质量或音频验收。当前预览固定为暂停、400 首示例输入和 4 首示例入选歌曲，不请求账号、模型或音频。截图 URL 带 `v=20261013`，避免旧图片缓存。

截图使用暂停状态下的项目生成图 `whale-idle.png`，不包含用户提供的锅盖鲸鱼娘 GIF 或其衍生图。素材来源与许可边界见 [第三方声明](../../THIRD_PARTY_NOTICES.md)。

预览入口与 React 18 要求见 [贡献指南](../../CONTRIBUTING.md#隔离-ui-预览)。更新截图应从客户端实际渲染结果截取，不使用虚构界面代替。
