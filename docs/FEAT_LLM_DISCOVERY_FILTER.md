# FEAT：LLM 筛选的平台发现候选（探索池重排）

日期：2026-10-05。用户确认的方向：不再让 LLM 只凭歌名/艺人"凭空"生成歌单，而是把网易云 `simi_song`/每日推荐的真实 CF 候选作为探索池，由 LLM 在其中**挑选排序**，本地规则继续负责执行。术语在 UI 中白话化或收进折叠详情。

## 分层职责

```text
网易云 CF（simi_song/每日推荐/私人FM）→ 候选从哪来（真实 trackId，无核对问题）
个人数据（偏好/反馈/冷却/来源线索）    → LLM 判断依据
LLM（低频、批量、有预算）             → 哪些值得听：挑选 + 排序 + 一句理由
本地规则（selection local-v4）        → 什么时候播：冷却/重复/禁播/反馈仍最后执行
```

## 数据流

1. **候选获取**（现有 discovery cache，重新在 LLM 模式启用）：种子取自输入曲库（`selectRecommendationSeeds`），`simi_song` + 每日推荐进缓存（上限 200、TTL 6h、低水位刷新）。N11"LLM 模式不调用网易云推荐入口"边界据此修订（用户 2026-10-05 决定），平台只做候选召回，不做逐曲推荐决策。
2. **LLM 筛选**（新模型用途 `discovery-filter`）：
   - 预留（`persona-reserve`）时由 Core 组装事实：口味画像（Top 艺人/权重、喜欢/少推荐数、探索率）+ 候选清单（序号、歌名≤24、艺人≤20、来源线索如"相似于《种子歌名》/每日推荐"），上限 30 首、字节上限 2600；
   - 提示要求只输出 `{"summary":"≤20字思路","picks":[{"i":序号,"why":"≤16字理由"}]}`，最多选 12 首；候选文本是数据不是指令（注入防护同现有措辞）；
   - 完成落库：`discovery_filter_v1 = {callId, at, summary, picks:[{trackKey, rank, reason}]}`（索引→trackKey 映射用预留时的 `facts_json`）。
3. **排序生效**：discovery cache 在 `usable()` 时把 `llmRank/llmReason` 戳到候选条目上；选择器加有界 `llmBoost`（Top1 ≈ +0.24，线性衰减），未入选候选保留可用（排序靠后），**筛选永远不把池子排空**。
4. **触发**：a) 调度器每 10 分钟检查 due（有候选、无进行中调用、筛选结果缺失或早于最近一次成功刷新）；b) 用户点"刷新新歌"后后台补跑一次。筛选过期随缓存 `clear()`/账号切换一并删除。
5. **降级**：模型不可用/预算不足/解析失败 → 未筛选候选照常参与（状态如实标注），错误分类沿用账本机制；失败只消耗已用量，不回退旧结果。

## 预算与门控（按用途分离）

| 用途 | 每日尝试 | 冷却 | 说明 |
|---|---|---|---|
| persona-summary / model-recommendations | 3（现状） | 1h | 不变 |
| discovery-filter | 12 | 15min | 只统计本用途；输入 ≤2600 字节；受共享 token 预算约束 |

`discovery-filter` 不要求"自动总结"开关：它是 LLM 推荐模式自身的一部分，但沿用真实账本、冷却与预算。路由沿用最近一次成功调用的 provider/model。

## UI 白话化（本轮同步）

- 发现状态：'大肥鱼从 X 首新歌里挑了 Y 首合口味的'、'正在找新歌…'、'大肥鱼正在试听候选…'、'需要先登录网易云才能找新歌'；不再出现"陌生候选/种子相似"字样。
- 歌单徽标：'已核对'→'可播放'、'not-found'→'网易云没有这首歌'、'ambiguous'→'同名歌太多，拿不准'、'lookup-failed'→'确认失败，稍后再试'。
- 选歌依据（折叠详情保留数字，但用白话）：'陌生池/熟悉池'→'新歌/常听歌曲'，'关系项'→'与种子歌曲的相关度'，'艺人集中惩罚'→'避免连续同一艺人的调整'。
- 「大肥鱼说」对入选新歌优先展示 LLM 的真实理由（`discovery.llmReason`）。

## 验收标准

1. LLM 模式下发现池来自平台候选且带来源线索；登录缺失时状态如实且自主选择回退常听歌曲。
2. 一次筛选调用后：入选候选带 rank/reason，选歌排序可观测地偏向入选项；未入选仍可被选中（长跑不空转）。
3. 预算：筛选调用进账本，12 次/日、15 分钟冷却生效；关 LLM 模式后平台候选入口同步停用。
4. 降级：模型不可用时状态标明，本地选歌不阻塞；注入样例（候选名含指令文本）不会改变输出结构。
5. 全量测试通过；真实宿主验证留给部署后（生产插件未重载的既有边界不变）。
