# MVP v0.1 产品规格

更新：2026-10-06。本文维护用户确认的范围与现行行为，已合并 N0–N20 和 U11 的规则修订。实现/部署状态和验收缺口统一见 [开发路线](PROJECT_PLAN.md)，取舍理由见 [决策记录](DECISIONS.md)，字段与接口见 [控制契约](CORE_CONTRACT.md)。设计提案和历史证据分别见 [design](design/README.md)、[spikes](spikes/README.md)。

当前优先网易云，QQ 接入按用户要求暂缓，保留双平台后续范围；本轮 UI 不以 QQ 为前置。实现或文档存在不代表真实验收通过。

## 1. 目标与范围

给 DSH 中的 DeepSeek 一套可成长的音乐人格。用户近期音乐是成长环境，Agent 在本地规则、探索与经历的作用下形成自己的偏好。这里的“听歌”指音乐选择与播放进度驱动的产品状态；v0.1 不执行音频理解，不声称模型实际感知了声音。

必须交付：网易云和 QQ、自维护 Provider、近期音乐导入、独立 Agent 偏好、跨会话记忆、本地自主选歌/暂时不听、用户控制、新歌探索、真实音频播放，以及 DSH 页面内可隐藏/重新显示的音乐控制悬浮条；鲸鱼娘插画作为非交互的音乐状态视觉，随待机、听歌、切歌状态切换。

不纳入：其他音乐平台、音频/歌词深度分析、Embedding/复杂推荐模型、逐曲 LLM 评价、主动人格反思、独立桌面聊天、语音、屏幕视觉、桌宠行为（喂食、抚摸、随机台词、屏幕漫游、养成或多宠物）、云同步、周报和手机端。余额挂件仅作 UI 参考，不是运行依赖；不直接复用其中的鲸鱼美术素材。

## 2. 首次使用

连接任一支持的平台（面板内显示扫码及登录状态）→ 导入近期音乐 → 显示实际导入数量与来源 → 建立用户环境 → 本地初始化 Agent 偏好 → 开始 DSH 会话。

- 目标导入 200～500 首，默认请求 300 首；用户不必同时登录两个平台。
- 近期记录优先；无法获得时使用我喜欢、用户歌单及本插件已存在的历史。首次安装没有插件历史可用。
- 记录每首歌曲的来源。收藏和歌单不能标成“近期播放”；缺失的播放次数、日期、流派保留未知。
- 同平台按平台 ID 去重；不同平台不凭标题强行合并。
- 少于 200 首可以继续，显示真实数量；没有任何歌曲时等待用户选择歌单或搜索点歌，不凭空初始化历史。
- 网易云可从 DSH 设置面板生成登录二维码，手机确认后由面板显示登录状态并提供音乐导入；登录材料仅保存在本机加密凭据存储。当前没有经过核实的 QQ 登录端点时，面板不得声称 QQ 支持扫码。

用户环境与 Agent 偏好独立保存。初始化采用用户环境、少量有界扰动和轻微初始偏置；保存随机种子，使重启不会重塑人格。默认不调用 LLM。

## 3. 默认设置与控制语义

| 设置 | 默认值 | 含义 |
|---|---|---|
| DeepSeek Listening | ON | 允许自主选歌、自动续播及 Agent 经历更新 |
| Human Playback | ON | 允许电脑输出声音 |
| Discovery | ON | 允许从陌生候选中探索 |
| Discovery Rate | 20% | 每次自主选歌进入发现池的目标概率，可调 0%～100% |
| 工作策略 | Normal | 正常本地决策；可切 Focus |

两个开关独立，四种组合都需要有定义：

| Listening | Human Playback | 行为 |
|---|---|---|
| ON | ON | 自主选歌并输出声音 |
| ON | OFF | 自主选歌与播放时间线继续，电脑静音；属于 Silent |
| OFF | ON | 停止自主行为；允许用户手动点播，标记为用户播放，不更新 Agent 听歌偏好 |
| OFF | OFF | 无自主听歌、无声音输出；允许操作设置和查看已有记录 |

### 用户操作

| 操作 | 行为约定 |
|---|---|
| 暂停 | 冻结当前播放/逻辑进度，禁止事件自动恢复；用户恢复或明确点歌后才解除 |
| 恢复 | 继续当前曲目；保持用户选择的静音和自主开关 |
| 下一首 | 用户明确换曲，绕过自主换歌冷却；暂停期间只改变曲目，保持暂停 |
| 指定歌曲 | 优先解析并播放指定曲目，解除暂停；不擅自取消静音或开启自主听歌 |
| 关闭自主听歌 | 当前 Agent 曲目暂停，停止自动决策与 Agent 经历更新；仍可手动播放 |
| “你自己听，我不想听” | Listening ON、Human Playback OFF；不等同暂停 |
| “今天别听歌了” | 暂停并设置到本地日期结束的自主禁止；到期只解除限制，等待下一安全节点或用户主动恢复 |
| “你自己选” | 解除用户暂停、开启自主听歌；保留其他明确禁播约束和静音设置 |

明确点歌与已有禁播约束冲突时，告知冲突并要求用户明确是否允许本次例外；不能悄悄删除约束。歌曲不唯一时展示候选；无权限或解析失败时给出实际失败原因，不把另一首当成点播成功。

Normal、Focus、Silent、Off 是快捷操作：Normal/Focus 启用自主听歌、设置工作策略并恢复电脑声音；Focus 减少中途主动动作，曲终仍可续播。Silent 设置 ON/OFF，Off 暂停并关闭两个开关。开关单独切换不改另一开关。"今天停止"后的禁止通过"你自己选"或界面恢复入口解除；被禁止时要求开始自主的命令报 `autonomy_blocked`，无候选时报 `no_candidates`，不得静默无操作。依据见 [U11](spikes/U11-mode-autonomy-restore.md)。

## 4. 自主选择与成长

真实宿主默认 LLM 推荐来源。低频模型根据代表歌曲、反馈和关系事实生成具体歌单，平台搜索核对后本地执行缓存；探索池还接收网易云相似歌曲/每日推荐等真实候选，由低频模型筛选排序。模型排名只作有界加成，未入选候选仍可用；模型不可用时未筛选候选仍可参与。展示总结与具体推荐分开，平台推荐保留为显式兼容模式，见 [N11](spikes/N11-model-playlist.md)、[N15](spikes/N15-llm-discovery-filter.md)。

用户主动「下一首」在默认候选无可播曲目时按同一规则回退输入曲库并说明来源；自主续播保持歌单/探索候选边界，不自动回退输入曲库，见 [N14](spikes/N14-user-next-library-fallback.md)。输入清空是另一个可撤销入口，计数归零；重置成长保留输入曲库。

音乐决策只在内部安全事件评估，不逐轮询问模型。当前曲目可正常结束；单次测试失败或工作状态抖动不触发换曲。用户暂停、禁播约束和关闭自主听歌优先于所有自动事件。

先过滤禁止曲目和已知不可播放曲目，再按探索率选择熟悉池/发现池，最后按 Agent 偏好、用户环境、工作上下文、新鲜度、随机项和重复惩罚评分。发现池无可用歌曲时回退熟悉池，保留设置值并记录实际回退。100% 是探索尝试目标，不保证平台始终有新歌。

用户的收藏、导入或评价不能直接覆盖 Agent 偏好。用户禁播是行为约束；用户说“喜欢这首”是反馈；Agent 自主选择是事件，三者分开存储。

“下一首”是用户触发的推荐换曲，不能因按钮由用户点击就标为用户点播。保留推荐来源与决策，只有指定歌曲的 `requestTrack` 记为用户选择；后续有效收听按实际自主/声音开关判定成长。

2026-10-03 新增 [歌曲反馈与重置](spikes/N10-feedback-reset.md)：喜欢/少推荐独立保存为可撤销规则，影响本地排序及相似种子；不同步平台收藏。用户可确认重置积累偏好，默认保留手动反馈，可选择一起清除，并撤销最近一次重置；保留输入曲库、账号、历史、禁播与 token 账本，不改变当前播放状态。

完成有效进度可有限更新 Agent 偏好；暂停、失败、瞬间切换不算完整听歌。静音经历与用户实际听到的播放分别计数；用户跳过不自动等于 Agent 讨厌，平台失败也不算负面偏好。临时 Session 权重只少量沉淀至长期偏好，并设上限、重复惩罚与衰减，避免“选中就加分”的自我强化。

偏好的差异需要在受控数据和可复现轨迹中验证；真实用户长期使用是否形成明显差异，不能仅凭初始化随机扰动宣布成功。

逐曲选择和解释不新增模型请求，也不持续向主对话注入状态。画像总结、模型歌单和发现筛选是计划内低频调用，受开关、冷却、次数和共享预算约束，全部入真实账本。自动总结默认关闭，精确门控见 [控制契约](CORE_CONTRACT.md)。

## 5. 桌面体验

DSH 主界面提供“肥鱼电台”侧栏入口，打开内嵌音乐设置面板；DSH 设置窗口提供同名页面。两处使用同一个 Core 状态与命令入口。面板包含自主听歌、声音输出、探索开关与探索率、四种快捷模式、暂停/继续/下一首/今天停止，以及平台实际连接状态。开关与模式即时保存；探索率明确点击保存。日常、专注和静听模式是开始听歌的快捷操作，关闭模式保持暂停。未配置平台时仍可保存设置，不显示虚假登录或播放成功。保存失败、服务断开时明确提示并允许重试；关闭面板不停止 Core。

音乐控制 UI 位于 DSH 的 `shell.overlay` 浮层槽位，不创建独立桌面窗口或宠物进程。页面右下角的状态条显示曲名、艺人和播放状态；点击展开暂停/继续/下一首，三点菜单提供快捷模式和完整设置入口。用户可隐藏、重新显示、拖动并吸附到左右边缘；进入肥鱼电台主面板时收起，离开后按已保存偏好恢复。可见状态使用本项目已有鲸鱼娘图，对应待机、播放和选歌姿态，不加入喂食、抚摸、随机台词或宠物状态机。布局参考 [DeepSeek Balance Whale Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)，设置卡和手势关闭参考 [dsh-api-dashboard](https://github.com/133563825as-ai/dsh-api-dashboard)。FishFM 只适配其中获 MIT 授权的 SwipeHandle 逻辑，并记录在 [第三方声明](../THIRD_PARTY_NOTICES.md)；余额挂件 `assets/**` 不在 MIT 范围，不复用其美术素材。

悬浮条和设置页都走同一宿主认证 RPC、同一 Core，不承载音频。隐藏控件或切换 DSH 页面不会停止播放；关闭整个插件则停止其播放和后台服务，DSH 继续工作。悬浮条位置保存在本机视口坐标并在窗口缩放时限制于可见范围；此功能不涉及多屏 DPI 映射或透明原生窗。

输入音乐支持标题/艺人/ID 本地搜索、分页和点播，主面板默认折叠，设置可查看。动态效果可选完整/轻量/关闭，遵循系统减少动态效果；公开测试包默认使用三张自有状态 PNG，姿态随播放状态变化。本地图片下提供默认关闭、保存在本机的「播放动效」按钮：开启且播放时使用已安装的锅盖 GIF，主面板/设置内的六种原图玩偶旋转、反弹、碰撞与压扁拉伸；暂停、断连、关闭立即收起，轻量/关闭/系统减少动态显示 GIF 配套静态图且不运行玩偶。装饰层不接收点击，不占用播放服务、不新增模型请求；切出面板清理，悬浮条只跟随开关显示 GIF。无本地素材时保留自有 PNG，开关不可用，素材不进公开 npm 包。菜单和拖动手柄支持键盘，布局与接入见 [U7](spikes/U7-phl-ui-motion.md)、[U8](spikes/U8-panel-layout.md)、[U10](spikes/U10-user-gif-cutout.md)、[U12](spikes/U12-playback-dolls.md)。

## 6. 验收清单

验收状态和缺口统一见 [开发路线](PROJECT_PLAN.md)，证据从 [spikes 索引](spikes/README.md) 查阅。离线测试、模拟预览、引用审计和单次真实播放不能替代完整验收；账号、版本和运行环境按记录日期理解。

| ID | 可观察结果 | 证据 |
|---|---|---|
| A01 | 两个平台各自完成登录、搜索、真实播放、暂停、恢复、下一首 | 版本、操作记录、脱敏日志与播放核对 |
| A02 | 可导入目标数量；数量不足、收藏/歌单降级和空结果均如实展示 | 导入统计及来源样例 |
| A03 | 两个开关四种组合、四个模式、暂停保持和到期约束符合第 3 节 | 状态迁移验证 |
| A04 | 用户点歌/下一首优先；禁播、暂停不会被自动事件覆盖 | 含慢请求、重复事件、命令冲突的轨迹 |
| A05 | 熟悉池、探索率 0/20/100%、候选为空和重复惩罚有效 | 固定随机种子的选择结果 |
| A06 | 用户环境与 Agent 偏好分离，重启后保留；Session 不覆盖长期偏好 | 数据前后对照、受控成长轨迹 |
| A07 | DSH 主界面及设置窗口可打开音乐设置，修改可持久化，连接失败如实提示；DSH 页面内音乐悬浮条可拖动、吸附、隐藏和重新显示，播放状态同步；切换面板或隐藏悬浮条不停止 Core/Playback | 主界面交互、浏览器视口与设置读回证据、Core 状态对照 |
| A08 | 多 Session 不抢占播放；插件退出停止音乐，DSH 正常工作 | 并发会话、卸载和异常场景记录 |
| A09 | 连续两小时自动听歌，用户未主动聊音乐；逐曲执行新增 LLM 请求为 0（计划内低频调用——画像总结、模型歌单、发现候选筛选——不受此限，但必须受开关/冷却/预算约束并全部入账本） | 请求计数、账本对照、工具注册/上下文注入检查与脱敏运行日志 |
| A10 | 静音、暂停、播放失败、进程重启不会伪增听歌次数或偏好 | 历史数据与进度对照 |

日常音乐状态不得持续注入主 Agent 上下文。逐曲零模型请求不等于插件工具描述绝无 token 开销；验证时应单独记录静态工具描述是否存在及其影响。
