# MVP v0.1 产品规格

更新：2026-11-11。本文维护产品范围、用户行为和验收标准；完成状态只看 [开发状态](PROJECT_PLAN.md)，字段／参数见 [控制契约](CORE_CONTRACT.md)，选择理由见 [决策摘要](DECISIONS.md)。

## 1. 目标与范围

FeiyuFM 是 DSH 中可成长的音乐控制插件：以用户音乐为环境，Agent 按本地规则、探索与有效经历形成独立偏好。“听歌”是选择和播放进度驱动的产品状态，不代表音频理解或模型实际感知声音。

v0.1 保留网易云／QQ、自维护 Provider、音乐导入、独立偏好与跨会话记忆、自主选择／暂时不听、用户控制、新歌探索、真实音频，以及可隐藏的 DSH 音乐悬浮条。**当前优先网易云与 UI，QQ 按用户要求暂缓，保留代码和双平台范围。**

不扩大到其他平台、音频／歌词深度分析、Embedding／复杂推荐模型、逐曲 LLM 评价、主动反思、语音／屏幕视觉、独立桌面聊天、云同步、周报或手机端。鲸鱼图仅表达音乐状态，不加入喂食、抚摸、漫游或宠物状态机。

## 2. 导入与初始化

连接平台 → 导入音乐 → 展示实际数量和来源 → 建立用户环境 → 本地初始化 Agent 偏好。无需同时登录两个平台，网易云扫码由设置面板发起、手机确认；未核实的 QQ 端点不显示扫码入口。

项目 HTTP transport 只在各自明确配置的可信 HTTPS origin 中使用登录态；拒绝跨源或降级跳转，正文和 Cookie 超限明确报错。新扫码不复用旧账号凭据，无新凭据不能算登录成功。固定接口包的调用路径及本地模拟验收范围见 [REV-05](spikes/REV-05-http-transport-boundaries.md)。

- 目标 200～500 首，默认请求 300。近期优先，不足时可用喜欢、用户歌单及插件已有历史；首次安装没有插件历史可用。
- 同平台按 ID 去重，不凭标题跨平台合并。来源、请求／导入数量如实保存；收藏和歌单不标为近期，缺失日期、次数、流派保持未知。
- 少于 200 首仍可运行；没有歌曲时等待歌单选择或搜索点播，不伪造历史。
- 用户环境与 Agent 偏好独立。初始化用环境、少量有界扰动及轻微偏置，保存随机种子，仅补缺失偏好，重启不重塑、不覆盖既有成长，默认不调用模型。

## 3. 默认设置与控制语义

| 设置 | 默认 | 含义 |
|---|---|---|
| DeepSeek Listening | ON | 允许自主选择、续播与 Agent 经历更新 |
| Human Playback | ON | 允许电脑输出声音 |
| 音量 | 35% | 播放栏常驻横条调节 0%～100%，本机保存最近一次非零音量 |
| Discovery | ON | 允许陌生候选探索 |
| Discovery Rate | 20% | 可调 0%～100%；默认 filtered 模式作筛选偏好，不保证逐曲比例；概率分流仅属旧兼容 |
| 工作策略 | Normal | 可切 Focus，减少中途主动动作，曲终仍可续播 |

| Listening | Human Playback | 行为 |
|---|---|---|
| ON | ON | 自主听歌并输出声音 |
| ON | OFF | 静听：自主行为和真实音频时间线继续，电脑静音 |
| OFF | ON | 停止自主；允许手动点播，不更新 Agent 偏好 |
| OFF | OFF | 无自主听歌、无声音；仍可查看记录和设置 |

| 操作 | 行为 |
|---|---|
| 暂停／恢复 | 暂停冻结进度且不被自动事件撤销；用户恢复保留声音／自主开关 |
| 音量／静音 | 拖动或键盘调节音量，0% 关闭声音，正值恢复声音。喇叭按钮静音／恢复最近一次非零音量。暂停、加载、换曲和重启保留设置，调节本身保持当前实例与暂停意图 |
| 上一首／历史前进 | 上一首固定实际播放历史快照；回退后的下一首先沿历史前进，如 A→B→C→B→C，再下一首才选新推荐；跳过禁播／不可播，边界明确报错，保持暂停，不制造反馈或有效收听 |
| 推荐下一首 | 到达历史最新位置后触发推荐，队列与曲库回退共用最近 50 次实际开始的硬性防重复规则；保持禁播、不可播和暂停，无窗口外可播歌曲时说明原因，保留当前播放 |
| 指定歌曲 | 解除暂停，优先解析指定曲目，不改声音／自主开关；冲突要求明确例外，重名展示候选，失败不擅自换歌冒充成功 |
| 关闭自主 | 暂停当前 Agent 曲目，停止自动选择及 Agent 经历更新；仍可手动播放 |
| 今天停止 | 暂停并禁止到本地日期结束；到期只解除限制，不自动解除暂停 |
| 你自己选／恢复自主 | 解除用户暂停及当日禁止、开启自主；保留其他禁播约束和静音设置 |
| Normal／Focus | 启用自主、设置策略并恢复声音 |
| Silent／Off | Silent 为 ON/OFF；Off 关闭两个开关并暂停 |

开关单独切换不改另一开关；“你自己听，我不想听”是静听，不是暂停。要求自主开始却被限制时报 `autonomy_blocked`，无候选时报 `no_candidates`，不静默无操作。详见 [U11](spikes/U11-mode-autonomy-restore.md)。

## 4. 推荐、反馈与成长

默认流程为“参考歌曲 → 网易云真实候选 → LLM 批量筛选 → 本地播放”。模型只从候选挑选并给简短理由，**只有入选歌曲进入默认自动池**；同账号未过期的多批入选曲累计最多 100 首，当前批次展示和“近期发现”仍只说明当前有效批次。平台空结果不调用模型；失败保留同账号仍有效的入选曲，否则等待或手动点播。旧直接生成歌名和仅加分策略保留内部兼容，见 [N22](spikes/N22-platform-first-recommendations.md)、[N25](spikes/N25-recent-playback-and-approved-pool.md)。

用户主动推荐下一首在入选歌单耗尽时可按同一过滤／评分回退输入曲库，并说明来源；自主续播不回退。推荐下一首保留推荐归属，指定歌曲与显式历史前后导航是用户选择，均可主动重播；真正开始仍进入最近播放窗口。选择本身不等于有效经历。

持续补歌按整个有效入选池的窗口外可播余量运行：余量降到 12 首时补充，补到 24 首停止；启动时补到目标。最近 50 次、当前曲、禁播、不可播、到期与探索设置都参与余量计算。成功新批次无需模型冷却；相同候选与相关偏好已评审时不重复请求，轮换参考种子并累积未过期候选。逐曲播放和“下一首”继续由本地执行，补批在后台独立运行，保留暂停优先。详见 [N27 持续补歌](spikes/N27-continuous-recommendation-supply.md)。

先过滤禁播、不可播及当前／刚播完曲目，自动续播、普通下一首和推荐队列均不得选择最近 50 次真正开始的播放实例对应的歌曲，并优先满足 30 分钟冷却；正常候选按偏好、反馈、关系和模型排名评分。没有正常候选时只可放宽时间冷却，不放宽 50 次窗口；缺少窗口外可播歌曲时等待新入选曲，沿用既有补批门控和预算，不通过重播保持续播。未开始的失败不入窗，恢复同一实例不重复登记；短暂成功播放后的跳过也入窗，但不改变有效收听或成长门槛。明确指定歌曲可重播，实际开始后仍入窗。窗口跨暂停／跨天／重启保留，换批或重置偏好不清空。同一歌曲按平台和歌曲 ID 判断。

送入模型的候选也避开当前曲目和最近窗口，沿用既有批量调度及预算，不逐曲请求。熟悉／陌生依据实际输入和有效经历，关闭探索或 0% 不自动播陌生曲；未知风格不猜。自动决策只在安全事件评估，工作状态抖动不触发换曲，暂停、约束和关闭自主始终优先。

| 数据／操作 | 边界 |
|---|---|
| 喜欢／少推荐／撤销 | 独立显式规则，影响排序与种子，逐曲传入筛选事实；不直接覆盖 affinity、同步平台收藏或推断整个艺人喜恶，少推荐不是禁播 |
| 重置偏好 | 可确认、可撤销；保留输入、账号、历史、禁播、账本及当前播放，默认保留反馈，可选择清除 |
| 清空输入 | 独立可撤销入口，曲库计数归零；与偏好重置分开，旧导入／成长不能写回重置前状态 |
| 有效成长 | 按真实有效进度有界更新；暂停、失败和瞬间切换不算完整收听。静音经历与用户听音分别计数，跳过／平台失败不等于负面偏好 |
| Session 影响 | 有上限、重复惩罚和衰减；不覆盖长期偏好，不因“选中”就增长。长期差异需受控轨迹与真实体验支持 |

推荐反馈区域提供默认折叠的“管理反馈”：查看喜欢／少推荐，按歌曲、艺人或平台 ID 搜索，筛选类型并每页显示 12 条；按最近反馈排序，可逐条撤销。撤销不要求该曲正在播放、不改变播放或成长；当前歌曲按钮仍校验播放实例。多窗口冲突先刷新列表，核对后再操作，不自动重试撤销。首版不含批量操作、历史反馈互改或播放入口，见 [U21](spikes/U21-feedback-management.md)。

音频宿主丢失、持续卡住 15 秒或可重试媒体失败时，原曲每次收听最多恢复一次，与过期地址共享预算；从确认位置继续、保持静音，不补计缺口。暂停／换曲立即取消；恢复失败后的替换仍有界，见 [N21](spikes/N21-playback-interruption-recovery.md)。

Windows 的远端音频由 Playback 服务先匿名下载到本机临时文件，再由 WPF 打开；宿主不动态编译下载器。下载期间仍可暂停／换曲，不携带系统默认凭据，成功预加载复用同一文件。下载失败与本机打开失败分别提示，失败不算收听或成长。完整下载可能增加首播等待，具体限制与现场待验范围见 [#19](spikes/ISSUE-19-wpf-public-media.md)。

逐曲选择、解释、控制不新增模型请求，不持续注入主聊天。总结／歌单／候选筛选共用真实账本和 token 预算，初始日预算为 100000 tokens，已有显式预算（包括 0）保留。筛选取消固定每日次数上限和成功冷却，后台失败退避 1 分钟；自动总结默认关闭并保留其独立次数与冷却规则。反馈不直接发起模型请求，后续正常补批可重评相关候选，质量收益需人工评价，见 [信号语义](research/PREFERENCE_SIGNALS.md)。

## 5. 界面与本机偏好

「正在听」页采用用户选定的 A 方案：人物在左，歌曲、反馈按钮和「大肥鱼说」在右，中等宽度也保持横排；较窄时歌词移到下方，人物缩小并继续与文本并排，长标题／艺人换行。人物区与右侧歌词顶端对齐，减少原上下布局的留白。常规喜欢／少推荐状态由按钮表达，重复说明收起，读取或错误提示保留。布局证据见 [U27](spikes/U27-companion-horizontal-layout.md)。

网易云逐行歌词的当前句随真实播放进度高亮并在歌词区内跟随。默认只显示原文，已有翻译与音译可分别开启。滚轮、触摸、键盘或滚动条浏览会暂停跟随，可用「回到当前句」恢复。暂停冻结当前位置；切歌取消旧歌词等待，隐藏页面停止歌词读取和滚动，不影响独立播放服务。

点击有时间戳的歌词行（含已开启的副行）或使用 Enter／Space，跳到该句的原文起始位置。以宿主实际定位为准，支持向前／向后与开头；暂停时跳转仍暂停，后来的暂停／换曲优先，旧应答不移动新歌。定位保留当前实例，不增加播放开始或最近 50 次记录，跳过的时间不计有效收听。无时间信息、未知时长或宿主不支持时保留显示并禁用跳转；加载／无词／纯音乐／纯文本／失败分别呈现，失败可重试。歌词不进入模型输入，不由模型生成、翻译或分析。接口与缓存见 [控制契约](CORE_CONTRACT.md)，证据边界见 [U26](spikes/U26-console-lyrics.md)。

DSH 侧栏主面板（含「电台设置」标签页）与 `shell.overlay` 共用认证 RPC 与 Core，不承载音频；设置只在主面板内提供，DSH 全局设置没有独立入口。隐藏悬浮条或切换页面继续播放；停用插件停止其 Core／Playback，DSH 继续工作。无平台也能保存设置，错误／断连如实显示并可重试。

网易云编号音频 CDN 的标准 HTTP 地址在解析后升级为 HTTPS，保留签名路径、参数和过期时间。下载超时显示“歌曲音频下载超时”，旧版未记录阶段的超时显示“音频准备超时”，均提供重新点播或换曲提示。平台解析、下载、本机打开和真实进度分别核对，下载与本机打开共用 12 秒准备预算。

“电台设置 → 网络连接”提供默认直连与自定义代理，设置按本机音乐数据保存。自定义地址接受 HTTP／HTTPS 无认证代理的主机和端口，保存后新发起的平台接口、社区 SDK 与音频下载请求使用该设置，在途请求完成原有路由。初次读取失败显示重试并禁用保存，未保存输入保留，另一窗口写入冲突时需读取已保存设置。应用层直连显式忽略环境代理，TUN／VPN 分流由用户在外部管理。

首次读取失败或超时须显示“读取失败”、原因与重试操作，不能无限显示“读取中”。平台可用时显示网易云扫码登录；单独曲库读取失败不阻断登录。平台状态读取失败时不把未知当作未接入，也不沿用旧状态开放账号操作；恢复后重新显示可用入口。

导入、清空与恢复确认成功后，之前发出的曲库读取不能把显示改回旧数据；正在使用的新搜索／页码保持，并按新库重新查询。平台操作之后的分项读取失败也须显示具体错误和重试，不能一边提示已退出，一边沿用旧授权展示导入操作。

曲库尚未读完也不能挡住登录入口；页面先展示可用平台，曲库独立继续读取。曲库超时后可重新查询，登录状态与已经读到的曲库数据保持。

首次使用在“正在听”内显示“欢迎使用feiyuFM”轻量卡片：连接网易云、导入参考歌单、开始听歌三个入口只切换现有页面、展开音乐平台并移动焦点，不自动登录、读取歌单、导入、播放或请求模型。第三步返回正在听，说明播放需手动开始，“喜欢／少推荐”影响本机后续推荐；可跳过或完成，设置页“使用指南”允许主动重开。

自动展示需初始化成功、实际曲库明确就绪，并利用面板已有偏好／历史读取确认没有使用证据。已有曲库、已授权／过期账号、播放／队列／历史或偏好等证据默认静默；失败、未知或曲库仍在读取时不把它当作新用户。版本化客户端记录保留跳过／完成状态，未完成引导可继续；Core 重启和同一客户端存储内的升级不重置。存储不可用时仅在本次使用保留状态，不阻止正常插件操作。窄屏、键盘、减少动态效果与 P0 错误优先保持。

- 主界面采用陪伴电台布局：角色与当前歌曲并列，保留一句选歌说明，下方展示整个入选池中当前可选的歌曲，先展示 3 首，其余展开；列表次序不承诺下一首。顶部依次为正在听／发现记录／偏好与反馈／电台设置，默认正在听，播放控制在所有页面的面板内底部常驻。电台设置在主内容区展示，宽屏左列为听歌方式、今天停止和听歌偏好，右列为输入／账号、模型／预算和界面选项；窄容器单列、标签自然换行。同一客户端共享待应用模型选择；切换页面保留未保存的探索率、导入来源与歌单选择。开关和模式即时保存，探索率显式保存；低高度窗口压缩角色区。见 [U24](spikes/U24-companion-player.md)，2026-11-02 设置标签页修订取代其初版右侧抽屉，陪伴布局继续取代 U23 默认多层设置折叠的主页面组织；2026-11-03 移除 DSH 全局设置的重复入口，只保留主面板入口。
- 暂停／换曲点击后立即显示请求中的反馈，不提前宣称音频已播放；同一待确认换曲的重复点击合并，暂停可取代未确认的播放／换曲请求。旧应答／错误不覆盖较新的暂停；准备音乐时加快只读播放快照刷新，隐藏或离开界面停止加速轮询，恢复稳定状态后沿用普通刷新。
