# 0.1.0 发布记录

日期：2026-11-04。首个正式版本，支持 **Windows／网易云**。发行准备中，npm 与 GitHub 发布结果在本页及 [结构化证据](evidence/0.1.0-20261104.json) 更新。

正式 npm 包名为 `dsh-feiyufm`，产品名称统一为肥鱼电台 FeiyuFM。旧测试包 `dsh-feiyufm-core` 的使用者应通过插件管理器移除旧来源，再安装新包；本机数据和 RPC 标识保持兼容。

## 这一版的变化

- 陪伴电台界面：大肥鱼与当前歌曲并列，正在听／发现记录／偏好与反馈／电台设置四个标签页共用底部播放控制；设置集中在主面板，移除 DSH 全局设置中的重复入口。
- 播放控制与延迟：上一首／下一首沿固定历史导航，越过最新位置才推荐新曲；取消、暂停与迟到应答保持用户命令优先。播放地址预取、下一首媒体准备与批量 SQLite 投影减少切歌等待。真实网易云预取命中的已有测量约为 0.68–0.77 秒，不代表所有网络和歌曲都达到该延迟。
- 最近 50 次实际开始的歌曲形成硬性防重复窗口；自动续播与普通下一首缺歌时等待补充。按整个入选池的余量持续补歌，低于水位时补充到目标；初始日预算 100000 tokens，筛选无固定每日次数或成功冷却，失败退避与共享账本保留。
- 可选 ASCII 背景频谱、doll 彩蛋、反馈管理与表达预设。频谱为模拟动画，不是音频测量；逐曲执行不新增模型请求。
- 统一版权声明，完善角色署名、第三方原许可、LGPL 源码与替换说明。详细变更见 [CHANGELOG](../../CHANGELOG.md)，使用条件见 [版权声明](../../THIRD_PARTY_NOTICES.md)。

## 安装与升级

在 DSH「插件 → 添加插件」输入：

```text
dsh-feiyufm@0.1.0
```

安装后点击“立即启用”。跟随正式版可用 `dsh-feiyufm@latest`；CLI 示例：

```sh
dsh plugin --profile web add dsh-feiyufm@0.1.0 --registry https://registry.npmjs.org/
```

`web` 对应实际使用的 profile。同一 profile 只启用一份 FeiyuFM；升级保留数据库，后端更新后从托盘完整退出并重新打开 DSH。单独 `npm install` 不会完成 DSH 插件注册。

## 验证范围

最终版本的回归、打包摘要、全新 npm 消费者安装、Windows DPAPI、官方 DSH 隔离 profile 及公开 registry 复验结果在结构化证据中分别记录。隔离宿主使用生成的静音媒体与合成 Provider／批准池，从该 profile 的实际安装目录加载生产 Core 模块，验证 RPC、播放控制、防重复、重启与退出清理；不请求真实模型或复用日常账号。

此前真实网易云／模型闭环见 [N23](../spikes/N23-model-route-completion.md)，播放延迟与日常 Desktop 用户反馈见 [R4](../spikes/R4-playback-delivery-and-reliability.md)。这些历史证据不改记为本次实包的新测量。

## 支持范围与未验项

- Windows 原生音频使用 WPF；本轮官方 DSH 宿主版本为 `0.2.1-rc.5`，宿主内置 Node `24.21.0`，维护环境 Node `24.22.1`。支持的 Node 范围为 `>=24.14.0 <25`。
- macOS Swift／AVPlayer／Keychain 适配随包提供，仍为实验性；真实登录、音频与退出生命周期尚未完成真机验收。QQ 暂缓，当前没有可用登录与播放链路。
- 完整 A01–A10、多平台／多会话长期组合、真实持续补歌与推荐质量的剩余缺口继续在 [PROJECT_PLAN](../PROJECT_PLAN.md) 保留。正式版本号不将这些未验项改记为通过。
- 本次不会重载日常 Desktop，不将隔离合成音频或 CI 跳过计为真人听音通过。
