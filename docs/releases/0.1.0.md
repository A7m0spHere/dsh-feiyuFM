# 0.1.0 发布记录

日期：2026-11-04。首个正式版本，支持 **Windows／网易云**。**npm 已上架，`latest` 指向 0.1.0，GitHub Release 与版本标签已公开。** 公开下载与全新 npm／官方 DSH registry 安装均已确认；[结构化证据](evidence/0.1.0-20261104.json) 保留本轮结果。

正式 npm 包名为 `dsh-feiyufm`，产品名称统一为肥鱼电台 FeiyuFM。旧测试包 `dsh-feiyufm-core` 的使用者应通过插件管理器移除旧来源，再安装新包；本机数据和 RPC 标识保持兼容。

## 这一版的变化

- 陪伴电台界面：大肥鱼与当前歌曲并列，正在听／发现记录／偏好与反馈／电台设置四个标签页共用底部播放控制；设置集中在主面板，移除 DSH 全局设置中的重复入口。
- 播放控制与延迟：上一首／下一首沿固定历史导航，越过最新位置才推荐新曲；取消、暂停与迟到应答保持用户命令优先。播放地址预取、下一首媒体准备与批量 SQLite 投影减少切歌等待。真实网易云预取命中的已有测量约为 0.68–0.77 秒，不代表所有网络和歌曲都达到该延迟。
- 最近 50 次实际开始的歌曲形成硬性防重复窗口；自动续播与普通下一首缺歌时等待补充。按整个入选池的余量持续补歌，低于水位时补充到目标；初始日预算 100000 tokens，筛选无固定每日次数或成功冷却，失败退避与共享账本保留。
- 可选 ASCII 背景频谱、doll 彩蛋、反馈管理与表达预设。频谱为模拟动画，不是音频测量；逐曲执行不新增模型请求。
- 统一版权声明，完善角色署名、第三方原许可、LGPL 源码与替换说明。详细变更见 [CHANGELOG](../../CHANGELOG.md)，使用条件见 [版权声明](../../THIRD_PARTY_NOTICES.md)。

## 安装与升级

在 DSH「插件 → 添加插件」输入：

```text
dsh-feiyufm@0.1.0
```

安装后点击“立即启用”。跟随正式版可用 `dsh-feiyufm@latest`；CLI 示例：

```sh
dsh plugin --profile web add dsh-feiyufm@0.1.0 --registry https://registry.npmjs.org/
```

`web` 对应实际使用的 profile。同一 profile 只启用一份 FeiyuFM；升级保留数据库，后端更新后从托盘完整退出并重新打开 DSH。单独 `npm install` 不会完成 DSH 插件注册。
