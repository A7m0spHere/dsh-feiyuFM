## 相对 0.1.2 的主要变化

1. **QQ 音乐接入与单账号数据隔离（#22）**：无监听端口 QQ Worker（锁定 `@yakult-green-tea/qq-music-api@3.3.7`）、扫码登录、曲库／歌词／相似推荐与 `320 → 128 kbps` 完整音源回退；单账号模式与 SQLite v11→v12 账号归档（`music_account_archive`）及旧资料显式恢复。
2. **受限／VIP 曲目跳过、批量预检与首播提速（#24）**：按当前账号真实完整非试听音源判定，QQ／网易云新增批量 `checkPlayability`（不返回或落盘 URL），网易云拒绝 `freeTrialInfo` 30 秒试听；发现预检＋24 小时退避、前台有界连跳、重新扫码清理不可播缓存，并叠加关闭 `QQ_PLAYBACK_HINTS_ENABLED`、后台预热首 20 首与进程内短期一次性复用 128 kbps 链接。
3. **无模型手动起播回退与状态同步修复（`6934a62`、`12f2915`）**：显式「开始听歌／下一首」回退链扩展为「入选池 → 输入曲库 → 平台已预检可播发现候选」，三池均空时做一次可取消刷新（低可播率最多 3 轮种子轮换），刷新失败后在播曲目保持播放状态与底层播放器一致；默认 `filtered` 自动续播仍只取 LLM 入选曲，最近 50 次硬窗口不变。
4. **常驻音量横条与可拖动进度条（#20、#21）**：0%–100% 音量滑轨与静音记忆贯通 Core／Playback／WPF／AVFoundation；底栏与悬浮条共用进度条与 `seek`。
5. **界面视觉与模块化拖拽电台设置（#23）**：修复宽屏左右白边，支持设置卡片拖拽排序、展开／宽展、自动补齐空白与本机保存；补齐 QQ 发现来源标签，悬浮条刷新跟随当前账号平台。
6. **网络代理与网易云 HTTPS 媒体升级**：电台设置新增默认直连／自定义无认证代理，网易云编号 CDN 自动升级 HTTPS 并补充下载诊断。

## 依赖安全审计评估（`npm audit --omit=dev`）

- 候选版本通过 `package.json` `overrides` 将传递依赖 `basic-ftp` 升级至 `6.2.6`、`follow-redirects` 升级至 `1.16.3`，并同步更新 `npm-shrinkwrap.json` 与 `scripts/verify-installed-package.mjs`。
- 联网实测 `npm audit --omit=dev` 告警从 **3 high + 6 moderate（共 9 项）** 降至 **2 high + 2 moderate（共 4 项）**：
  - `body-parser`（high）：位于 `@neteasecloudmusicapienhanced/api` 的 Express HTTP 服务入口；肥鱼电台不启动其公网 HTTP 监听，运行期无入站解析暴露面。
  - `node-forge`（high）：网易云原有加解密依赖链（0.1.0／0.1.2 既已存在），本轮无新增调用面。
  - `ip-address`（moderate）与 `qs`（moderate）：均位于未对外暴露的传递依赖链中，不接收不受信任的公网 HTTP 入站请求。
