Windows／网易云 Beta，Node `>=24.14.0 <25`，本轮使用官方 DSH `0.2.0-rc.2` 的隔离 Web profile。macOS 的 Swift/AVPlayer、Unix socket、Keychain 源码随包提供，列为实验性适配；不能声明完整 macOS 支持已验证。QQ 接入仍暂缓。

## 相比 beta.2

- DPAPI 凭据助手明确随 npm 包提供，修复全新安装缺少助手的问题；兼容 Windows PowerShell 5.1 的程序集加载。
- 音乐模型请求按 DSH 的实际模型能力设置推理参数，避免对不支持推理控制的自定义模型强传 `off`。
- 输出耗尽与仅推理无最终回答分别反馈，不应用截断结果；输出上限可设 64–4096，保留默认值、旧歌单及共享预算。真实协议路线、模型筛选、入选曲播放与日常 Desktop 重启补验见 [N23](../spikes/N23-model-route-completion.md)。
- U17：慢平台导入不再阻塞播放控制；输入曲库支持全部歌曲的分页和搜索，改进平台断连反馈。
- U18：手动找歌/换批取消 15 分钟模型冷却和倒计时。自动筛选继续受冷却约束，手动与自动共用并发、每日次数、预算和账本；平台节流和候选缓存保留。
- U15/U16：主面板分区布局、请求阶段和失败反馈优化。
- 开发登录命令正常结束后清理二维码图片与临时 key 文件；移除误放的 ComfyUI 资料。
- macOS 源码适配加入 Swift/AVPlayer 播放、AF_UNIX 通信、Keychain 凭据与 Helper 生命周期。
- [REV-01](../spikes/REV-01-import-reset-race.md)：清空曲库、重置偏好和撤销重置使旧在途及排队导入失效，返回取消结果；暂停不受慢导入阻塞。
- [REV-02](../spikes/REV-02-credential-cleanup.md)：凭据删除失败明确可见，内存会话仍停用，保留撤销引用和清理重试；只有实际删除后提示成功。
- [REV-03](../spikes/REV-03-snapshot-ordering.md)：所有快照入口统一去旧，同 revision 用 commandVersion 保留重启暂停，迟到响应不回退显示。

## 安装与边界

本次版本为 `dsh-feiyufm-core@0.1.0-beta.3`，发布到 `beta` 标签，保留 `latest` 在 beta.1。通过 DSH「插件 → 添加插件」输入固定版本或 `dsh-feiyufm-core@beta`，安装后点击「立即启用」；CLI 可用 `dsh plugin --profile <实际 profile> add dsh-feiyufm-core@0.1.0-beta.3 --registry https://registry.npmjs.org/`。单独 `npm install` 不完成插件注册。

同一 profile 只启用一份 FishFM，升级不删除数据库。后端更新需要完整退出并重启 DSH。Beta 不代表稳定 v0.1 的两小时、多会话、完整窗口组合、推荐质量及 macOS 真机验收已经通过。

依赖版本未升级；许可和素材边界沿用 [第三方声明](../../THIRD_PARTY_NOTICES.md)。逐曲播放不新增模型请求。
