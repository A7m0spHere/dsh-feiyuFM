# 0.1.0-beta.2 发布记录

日期：2026-10-07。状态：npm 已上架；版本、标签、公开 tarball 下载及 npm/DSH registry 重新安装均已确认。

## 范围与安装

包名 `dsh-feiyufm-core`，版本 `0.1.0-beta.2`，公开 npm 的 `beta` 标签；保留 `latest` 在 beta.1，不将本次测试版标为稳定版。限定 Windows、Node `>=24.14.0 <25` 和网易云；DSH 历史实测版本为 `0.2.0-rc.2`。

在 DSH「插件 → 添加插件」中输入 `dsh-feiyufm-core@0.1.0-beta.2`，安装后点击「立即启用」。跟随测试版用 `dsh-feiyufm-core@beta`。同一 profile 只启用一份 FishFM，升级通过插件管理器卸载旧来源、再添加新版，不删除音乐数据库。后端更新后需正常退出 DSH（含托盘）再启动。

- [N22](../spikes/N22-platform-first-recommendations.md)：参考歌曲 → 网易云真实候选 → LLM 挑选 → 本地播放。只自动播放入选歌曲，按批补充，保留暂停、原有数据和预算；主面板显示歌单、理由和换一批，模型与用量放在推荐设置。
- [N21](../spikes/N21-playback-interruption-recovery.md)：播放失败、时间线卡住与连接中断有界恢复；原曲一次重解析，保留位置、静音和有效收听，暂停/换曲优先。
- [U14](../spikes/U14-compact-layout.md)：主面板、设置与悬浮条紧凑布局，播放与反馈合并、四模式单行。
- [U12](../spikes/U12-playback-dolls.md) / [U13](../spikes/U13-easter-review-fixes.md)：默认关闭的无文字彩蛋开关、完整 GIF/静态图/六张 doll PNG 随包；同源窗口偏好同步和高窄布局适配。
- 仓库导航与 README 重新整理，预览采用实际客户端单列局部取景。
