# #7 首轮真实推荐质量基线

记录日期：2026-11-01（Asia/Shanghai）。对应 [Issue #7](https://github.com/A7m0spHere/dsh-feiyuFM/issues/7)；最新状态和工程验证统一维护在 [PROJECT_PLAN](../PROJECT_PLAN.md)，操作方法见 [研究说明](README.md)。

## 方法与来源

本轮从用户本机数据库以 `DatabaseSync({readOnly:true})` 在同一读事务中冻结一批已保存的网易云候选、参考歌曲、筛选结果及其账本。没有启动 Core、平台请求、模型或播放器，没有修改用户偏好、预算、播放规则或原数据库。采样时看到的 83 条已完成筛选账本不等于 83 份研究样本：历史入选名单没有逐批完整保留，本轮只使用一份可与账本和候选归属核对的完整批次。

| 项目 | 本轮值 |
|---|---|
| 样本类型 | `local-snapshot`，一批真实历史结果；目录元数据仅留本机 |
| 批次完成时间 | 2026-11-01 15:19:39.675 +08:00 |
| 冻结时间 | 2026-11-01 15:35:44.122 +08:00 |
| 输入 SHA-256 | `d991189f0a44ae022063c2fc890e84e8710fd67cc082fe64a1938f86b6a8c84a` |
| 导出工具基线 | `7f62f84`；原调用所加载的插件提交未知，不由采样工具版本反推 |
| 评价工具 | [`6e161b0`](https://github.com/A7m0spHere/dsh-feiyuFM/commit/6e161b0f26771a89c24f51a3c424a4631c3b81be)；Windows / Node 24.22.1 |
| 候选与入选 | 4 首候选，1 首入选，4 首参考曲 |
| 固定参数 | `top-k=6`；不足六首按实际数量报告，不补入其他批次 |
| 比较对象 | 已保存 LLM 排名与 `distinct-artist-first`，共同排除后均只有同一首 |

回放将已保存 `picks` 重建为响应，经生产 `finishSummary` 解析；这不是原始模型文本重放、模型重新推理或完整 Core 自动播放顺序复现。用户指令、本地评分、冷却和随机选择等没有被重建。两次不含反馈的回放在同一输入和参数下得到一致的 JSON 报告、Markdown 报告和评价表；纳入反馈后仍使用同一输入 hash。

## 人工评价与指标

用户首次提交“一般、没听过、实际播放过、理由可信”，并在编号澄清中明确对应匿名候选 `c001`，随后补评同一冻结批次的其余三首。保留初次反馈和回放产物，另生成补评反馈与回放目录；输入 hash 和快照不变，`confirmedHuman=true`。

| 匿名候选 | 原模型入选 | 明确评价 | 本轮试听前是否听过 | 实际播放 | 模型理由可信度计入值 |
|---|---|---|---|---|---|
| c001 | 是 | 一般 `try` | 没听过 | 用户自报播放过 | 可信 `true` |
| c002 | 否 | 一般 `try` | 听过，用户说明来自社媒 | 未知 | 未知 `null` |
| c003 | 否 | 一般般，映射为 `try` | 没听过 | 未知 | 未知 `null` |
| c004 | 否 | 愿再听 `worth` | 没听过 | 未知 | 未知 `null` |

用户对后三首也填写“可信”，但这三首没有保存的模型推荐或拒绝理由，无法确定这项回答对应的模型理由。原始回复保存在本机来源备注，不计入模型理由可信率；不将未提供的理由补造为可信。三首的实际播放均按明确回复保留未知，偏好评价不推导播放成功。

平台候选的 `newDiscoveryJudged=4`，分母仅含同时给出明确评价和是否听过的曲目；c004 满足“此前未听过且愿再听”，因此该批出现 1 条人工新发现评价线索。c004 的实际播放未知，不能据此记为已验证播放的新发现或 #11 连续试用成果。原筛选名单及研究变体仍只有 c001，`newDiscoveryJudged=1`、新发现数为 0。“一般”不等于“不喜欢”，也不等于愿意保存或继续听。四首来自同一人、同一批次，不能外推整体推荐质量。

历史 `known=true` 表示调用前存在相同歌曲键的有效进度记录；用户 `heardBefore=false` 表示本人认为以前没有听过。c001 的两种记录保留各自来源，具体差异原因未知。c002 的社媒接触属于用户明确的站外熟悉度，即使本机历史熟悉状态未知，人工评价仍记录听过。不覆盖冻结快照，不写入产品偏好。人工 `played` 来自用户自报，本轮没有另行验证该次播放的取链、音频或宿主耗时。

## 分析与后续依据

- 原排名与研究变体完全相同，只有一首入选，本次无法判断艺人优先重排的收益；生产策略保持不变。
- 入选曲被评为“一般”，同时理由被认为可信。理由可信与歌曲命中喜好是两个独立结果，不把其中一个代替另一个；用户认可理由也不构成音频相似性或模型听感的证明。
- 未入选的 c004 被用户评为“愿再听且此前没听过”，形成一条明确的筛选遗漏线索；同批入选曲为“一般”。这说明本批平台候选中存在正向评价曲目，尚不能断言模型筛选整体变差，也不能根据单条反馈确定拒绝原因。
- `distinct-artist-first` 只重排已入选集合，不能补回未入选的 c004。本轮下一步的研究重点是核对筛选事实与选择门槛，单纯重排不覆盖该线索；未保存的模型拒绝原因保持未知，4 候选／1 入选也不足以证明供给瓶颈的根因。
- c004 可作为后续核查的发现线索，但模型理由缺失、实际播放和权限未知，不记为已确认的分享候选；这不启动主动分享功能。
- 后续优先利用正常使用自然产生的较完整批次，继续冻结同批材料、扩充跨批次样本，检验正向评价候选未被保留的现象是否重复，再判断是否提出 #9/#10 的小范围实现。保留最近 50 次硬窗口和既有预算，不为研究增加调用。

本报告是一轮单批、四曲人工反馈，覆盖该批全部候选，但不计入 #11 连续试用人数、时长或完成记录，不提升 A01–A10 的完整验收。历史短窗重复指标不作为 N26 最近 50 次实际开始的硬窗口验收。按本轮约定，#7 保持打开。

原始快照、歌曲与艺人、参考曲、反馈文件和工具来源记录只保存在本机忽略目录；本报告只提交匿名汇总。后续回放必须使用该冻结输入和对应反馈，不重新导出最新批次后沿用旧评价。
