- 主播放器保留小尺寸鲸鱼娘，准备/播放/静音/暂停/断连各有对应状态；不再持续摇动整张插画。

- 手动模式的第一首点播保持自主开关；无候选等业务错误不再将健康的 Core 连接误标为断开。

## 重构与运行

维护 `src/ui/client/` 的九个模块，生成 `src/ui/dsh-client.js`。`npm run build:client` 单独生成，`npm run build` 自动生成并构建；`npm run check` 拒绝过期的生成文件。React 继续由 DSH 提供，无新增生产依赖。

`npm run preview:ui -- --react-root <已有 React 18 的 node_modules 目录>` 启动固定资源白名单的 loopback 预览。预览用同一生产组件和隔离 mock controller，不读生产库、不登录、不播放声音；正常动效演示按钮只在预览中模拟非 reduced 环境，未修改用户 OS 设置。
