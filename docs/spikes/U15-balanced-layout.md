# U15：歌单与设置分区布局

2026-10-07。用户截图显示歌单过宽、所有设置集中在右侧，右列把页面撑高，歌单下方出现大片空白。本轮调整 N22 主面板布局，保留现有颜色、字号、素材与操作。

## 调整

- 主面板上半区为歌单与常用听歌控制两列，宽度约 59:41；控制列至少 300px，不再固定为 280px。
- 输入与连接、推荐反馈、界面选项移到下方三列，减少单侧堆叠。容器不足 740px 时恢复单列；设置席位继续先显示听歌控制，再显示歌单和曲库等选项，DOM 与视觉顺序一致。
- 歌曲行上下内边距由 9px 收到 7px，分区间距为 12px。播放器角色跨歌曲信息与操作两行，减少角色撑出的额外高度；窄容器保留操作区全宽换行。
- 模型、预算、平台、曲库和重置仍使用原有折叠入口，命令、保存逻辑与播放服务没有改变。

## 同一数据前后对照

使用已有 React 18、Playwright/Edge 和 `npm run preview:ui -- --react-root D:/AI项目/dsh-phl/node_modules --port 4191`；旧版 bundle 从调整前的 Git HEAD 读取，新版来自客户端构建。1280×950px 视口中，主面板容器宽 1050px，四首模拟入选歌曲，默认折叠。

| DOM 测量 | 调整前 | 调整后 |
|---|---:|---:|
| 页面内容高度 | 1105px | 928px，减少约 16% |
| 歌单 / 常用控制宽度 | 724 / 280px | 592 / 414px |
| 上半区左右高度差 | 255px | 29px |

数值依赖内容与宽度，不是生产账号的固定高度。截图见 [浅色主面板](assets/U15-compact-light.png)、[深色窄设置页](assets/U15-settings-dark.png)，尺寸与结果见 [浏览器记录](assets/U15-layout-results.json)。
