# REV-01：重置后的旧导入取消

2026-10-13，修复 [issue #1](https://github.com/A7m0spHere/dsh-feiyuFM/issues/1)。

真实 Core Host 与 Provider Facade、内存 SQLite、合成歌曲及可控 Provider Promise 复现：清空输入后迟到导入把数量从 0 改回 1；重置偏好、撤销重置同样接受旧结果。

Core 在接收导入时捕获独立输入代次。成功的清空、偏好重置或撤销重置更新代次；开始请求及写入前校验，旧在途和排队请求返回 `cancelled`。正常导入及暂停优先保留，不复用播放命令版本，也不把命令重新放入慢平台队列。

回归以两个客户端请求 ID 模拟共享 Core，覆盖客户端停止等待后 Core 仍在工作的情形；验证曲库保持为空、偏好不被重建、排队旧工作不再调用 Provider、重置后新导入成功。另覆盖仅暂停时旧导入仍成功。

Windows/Node 24.14.0：Core Host、反馈与 DSH 设置针对性回归通过。使用合成凭据和歌曲，不修改日常数据库；本轮证据不代替原生多窗口现场验收。
