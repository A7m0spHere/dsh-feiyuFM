# U13 彩蛋开关与玩偶边界复核

日期：2026-10-07。范围为 U12 的彩蛋开关、素材可用性、播放门控、跨窗口状态与绘制边界。

## 两项已复现的问题与修复

1. 同源窗口之间的开关偏好不同步。旧实现只在创建 controller 时读取 localStorage；A 页面开启后，已打开的 B 页面仍为关闭，播放时仍使用原静态 PNG。两个独立隔离页面实测 `A=true / B=false`，对应回归在修复前失败。现在监听该 localStorage 键的原生 storage 事件，读取当前值后更新显示；不处理 sessionStorage 和其他键，不再次写回或发送 Core 命令，controller 退出时移除监听。清空偏好时恢复默认关闭。
2. 旋转和碰撞形变超过窄视口。网格只按基础尺寸安排玩偶，272×1800 和 96×620 的容器可在数帧内出现越界裁切。新增回归在旧实现中报 `272x1800: horizontal clipping`。现在把旋转后的图像外接框与底部锚点偏移一起用于边界适配；绘制和碰壁使用同一几何结果，只在空间不够时等比缩小，不改人物原图或压扁/拉伸比例。普通空间尺寸足够时不缩放。

## 验证

修复前两项新回归均失败，修复后 28 项相关测试通过。几何回归覆盖 272×620、272×1800、96×620、单玩偶及临时 1×1 容器；另保留 60 秒旋转/碰撞/缩放及正面碰撞反弹检查。跨窗口回归覆盖开启、关闭、偏好清空、忽略 sessionStorage/其他键、零 Core 调用与监听清理。

隔离浏览器复验两个独立同源页面由 `false/false` 一起变为 `true/true`；B 页面播放时随 A 开关切换 GIF/六个玩偶和静态 PNG/零 Canvas。320×1900 实际高窄视口无横向溢出，六个资源加载正常。这些是隔离页面与模拟数据证据，没有重载生产 DSH，也没有操作生产账号、数据库或音频；完整生产窗口组合继续保留未验。

最终验证：全量 393/393 项测试通过，126 模块检查、构建/debug smoke 与验收引用审计 10/10（68 份文档，零断链）通过。两个独立浏览器页面控制台均无 error/warn；复验关闭状态再次同步为 `false/false`。本地交付截图为 `.tmp/U13-review-fixes.png`，临时预览与日志验证后清理。没有发布 npm 新版本。
