# N3 真实发现池

2026-10-02：代码已接入并经离线测试。官方 desktop 音乐插件独立重载后，真实 Core 返回 34 首陌生候选、UI 显示“网易云每日推荐”；自然曲终/成长、手动刷新及完整 Adapter 重载的现场结果在本文件后续补充。

## 实现

- Host/facade 维护后台缓存，selector 同步读缓存，不等待网络。登录、导入、开关/概率改变及低水位/TTL 触发调度；开始刷新不会解除暂停。
- 陌生定义：不在用户导入环境，也没有插件有效收听历史。只选未过期、没有本机不可播记录的候选；selector 另做禁播、冷却和重复过滤。
- 有效自主收听后的歌曲进入 Agent 已知歌曲查询，退出发现池；不增加用户导入曲库数量。原始推荐来源保留在对应播放实例的成长/历史事务载荷中。
- 参数：批次 40，缓存最多 200，TTL 6 小时，低水位 10，自动刷新最短间隔 30 分钟，手动刷新 1 分钟，临时失败退避 5 分钟。候选及预算持久化，重启和关闭/开启不能绕过预算。
- 单一 in-flight 请求；停用探索或账号变化取消发布资格，晚到结果不得补入池。有效缓存遇临时失败保留，过期和退出/切换账号清理。分别显示 disabled/idle/refreshing/ready/empty/error/unavailable/login_required。
- 认证设置 RPC 新增 `fishfm/discovery-refresh`，只调度刷新；返回同一 Core 的投影与能力标志。旧宿主模块未重载时隐藏手动刷新按钮，后台发现与状态展示仍能运行。
- 播放中的静音/声音切换修复了事件版本同步；WPF 与契约替身都拒绝旧版本控制，不能因新的静音命令丢掉进度/曲终。
- 生产诊断统计每个真实进度事件，但轨迹按每实例每类型 5 秒采样，避免高频进度挤掉选择、历史和成长里程碑。

## 离线验证

缓存/Host/认证 UI/传输专项 39 项通过；新增显示测试区分探索目标与实际候选，缓存测试覆盖陌生过滤、重复、已听/不可播、预算、single-flight、账号变化、临时失败/TTL、关闭后的晚到结果及刷新中暂停。另有播放中静音/恢复声音后自然结束的命名管道回归，以及 10000 个高频事件保留精确计数和里程碑的测试。

实现阶段全量 264 项通过，89 模块检查、构建/调试冒烟与审计通过；随后新增固定种子 1000 次决策的 20% 分布与重放检查，selection/cache 专项 18 项通过。刷新状态进一步区分账号缺失、接口缺失与暂时失败；账号推荐遭 301/401/403 拒绝时，将凭据引用标为 expired 并清除候选发布资格。

最终代码全量 265/265 通过，89 模块检查、生成一致性、构建/调试冒烟和扩展后的证据/文档引用审计均通过。本轮没有新增依赖。

0/20/100% 的池选择、重复惩罚与固定种子轨迹由 selection 专项覆盖；短跑不要求实际比例恰好等于 20%。真实账号来源仍是平台账号推荐，N4/N5 风格画像与种子推荐未实施。
