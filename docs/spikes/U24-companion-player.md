# U24：陪伴电台界面与设置抽屉

2026-11-01，用户选定本次交互预览第二版“陪伴电台”，明确要求保留一个设置 UI 入口，以及原 doll 小开关。当前交付与待验只在 [PROJECT_PLAN](../PROJECT_PLAN.md) 维护；行为和 DTO 分别见 [MVP](../MVP.md) 与 [控制契约](../CORE_CONTRACT.md)。

## 实现

- 主面板用角色与当前歌曲并列、下方三列可选歌曲和面板内底部常驻控制；窄窗口纵排，低高度窗口压缩角色区。正在听、发现记录、偏好与反馈使用同一控制器；返回反馈页时恢复已展开管理区的刷新。
- 主面板一个“电台设置”按钮打开右侧抽屉，使用原生 dialog 的模态／焦点与 Escape 语义。听歌模式、导入／账号、模型、共享预算、输出额度、界面与悬浮条均接原来的真实入口；抽屉中也能暂停／换曲。原生 DSH 设置席位仍可使用，待下次手动挑歌应用的模型选择保存在客户端控制器，由不同席位共享。
- 保留 U12/U13 的中性无障碍名 `aria-label="小开关"`，无可见文字或 title；默认关闭、ArrowLeft／ArrowRight、同源偏好同步、GIF／静态图／六个 doll PNG 和暂停清理沿用原实现。没有新增素材、依赖或第三方源码。
- UI 可选池展示当前窗口外、未过期且满足约束的整个入选集合。Core 只增加最多 100 首的安全只读投影；最新批次与发现记录继续保持原语义，旧宿主缺字段时明确标为当前批次。列表不承诺播放顺序，N27 调度、N26 防重复、预算、成长和平台权限规则不变。
- 设置不创建第二个 Core，播放继续由独立音频服务承担。迟到的播放／曲库代次同时保护可选池投影；UI 请求反馈、暂停优先和已确认快照排序继续沿用 U23。
