# U8 主面板与设置布局优化

2026-10-03：按用户要求优化前端布局，沿用既有 PHL 配色、组件、短促动效和鲸鱼娘素材。本次验证使用生产客户端 bundle 与隔离模拟数据，不请求真实账号、模型或音频，不替代真实 DSH 宿主验收。

## 布局与行为

主面板保留顶部播放器，先放播放控制，再显示独立的“大肥鱼说”及可展开依据。宽容器下，左侧为本地画像、模型总结和偏好记录，右侧 320px 集中听歌方式、开关、探索率、输入与平台连接。容器宽度不足 740px 时改为单列。

设置席位采用单列，听歌设置排在画像之前；DOM 顺序与视觉顺序一致。输入曲库仍默认收起，展开后保留搜索、点播与分页；平台导入来源、扫码状态与错误重试入口继续可用。界面与悬浮条设置默认折叠。

画像以艺人标签和经历/探索数字展示核心事实；今日/累计已知 token、尝试与未知次数保持常显。自动总结、账本预算、调用历史和详细偏好按需展开，使用原生 `details`。模型选择与生成按钮、预算标签与保存按钮在窄容器中自动换行。输出上限的可选最大值与当前保存值分开，降低至 64 后仍可恢复到 256。

逐曲回复由本地规则生成，模型总结按需调用；此次 UI 改动没有新增自动模型请求。旧 Core 未提供自动总结策略或输出上限设置时，界面显示明确说明并禁用相应选项。

## 验证结果

预览启动：`npm run preview:ui -- --react-root D:/AI项目/dsh-phl/node_modules --port 4179`。复用已存在的 React 18 UMD，不安装依赖；`prototypes/fishfm-ui-preview.html` 提供独立 N9 显示数据与模拟 RPC。

本轮在 Codex 浏览器实际渲染和操作：

- 1280px 主面板为两列，390px / 320px 为单列；440px 设置面板顺序正确。浅色、深色与所有主要折叠区展开后均无横向溢出。
- 自动总结、预算、曲库、平台和偏好明细可展开。预算区用 Enter 收起/展开、Tab 进入输入框，焦点边框可见；后台刷新保持展开状态。
- 输出上限保存 64 后控件仍允许最大 256，并成功恢复保存。模拟总结进行时暂停可用，完成后仍保持暂停；这是客户端交互证据，不是生产播放证据。
- 今日/累计 token 与未知次数常显，曲库默认收起。页面控制台没有捕获到 error / warn。
- 客户端与展示专项 20 项通过；全量 318 项通过；108 模块检查、客户端生成一致性、构建与调试冒烟通过。
