# U2 面板逻辑（`src/ui/panel.mjs`）

- 日期 / 环境：2026-09-27，Windows 11，Node 24.14.0。
- 状态：**面板逻辑已实现并通过 11 项测试**，其中一项直接驱动**真实 Core** 的快照；`prototypes/fishfm-ui-preview.html` 是可交互前端原型，并使用三张先前生成的鲸鱼娘姿态图演示待机/听歌/DJ 状态切换；**生产桌面窗口壳与托盘未做**。图像只随音乐状态变化，不包含宠物行为。因此 **A07 不勾选**。
- 相关任务：[PROJECT_PLAN](../PROJECT_PLAN.md) U2；验收关联 A02/A03/A05/A07。

## 为什么先做逻辑而不是窗口

窗口壳需要先选定并验证实现方式（P0-05 已记录当前桌面工具链边界）。但面板的**产品语义**不需要窗口就能确定和审查，所以把"显示什么、能点什么、出错说什么"放在一个纯函数模块里：

```
snapshot(+平台/桥接/气泡状态) →  view model + 可用操作
```

这样窗口壳以后**不持有产品决策**，只负责渲染与输入。

## 覆盖的语义（全部来自 MVP 第 3 节，逐条有测试）

| 要求 | 实现 |
|---|---|
| **两个开关独立，四种组合都有定义** | `describeSwitches` 返回 `key`（`on-on`/`on-off`/`off-on`/`off-off`）与 `name`（`audible`/`silent`/`manual-only`/`idle`）+ 中文标签 |
| Normal/Focus/Silent/Off 是**快捷操作，不是第二套状态机** | `deriveMode` **从 settings 推导**（`silent` 由 `listening && !humanPlayback` 得出），面板不自存模式 |
| 探索率 | 核心存 `0.2`，面板显示 `20%`（`discoveryPercent`） |
| **曲目提示状态** | 现有 `updateBubble` 只在**曲目变化**时重置短暂提示（轮询同一首不会反复弹）；`describePanel` 给出 `visible`/`fading`/`remainingMs`。预览另有常驻音乐控制气泡和状态姿态切换；尚未接入生产 UI 壳，不显示随机台词 |
| **"上一首"不是交付项** | 操作列表里没有它，并有断言守着；`NOT_DELIVERED` 显式列出 |
| 每个操作带**确切的 core 命令** | `pause`/`resume` 按暂停状态互换；开关与模式都带 `command` |
| 登录/导入/错误/离线状态**可操作** | 见下 |

## 状态一律给"能做什么"，且不同问题不混为一谈

| 状态 | 面板显示 | 可做的操作 |
|---|---|---|
| 未登录 | "还没有连接音乐平台" | **`sign-in`**（此时**不显示**播放/导入按钮——不给按不动的按钮） |
| 登录过期 | "登录已过期" | `sign-in` |
| 平台错误 | "平台暂时不可用" + 真实原因 | `retry-platform` |
| 桥接断开 | "控制面板未连接到音乐服务" + **"音乐仍在后台运行"** | `retry-connection` |
| 导入降级 | "已改用**我喜欢**导入"（用用户语言说来源） | — |
| 还没导入 | "还没导入音乐" + 原因 | `import` |
| 播放失败 | 按错误码给**真实补救**：`media_failed`→重试该曲、`no_candidates`→去导入、`media_unavailable`（会员/地区限制）→**不给假补救** | 视情况 |
| 版本不匹配 | "版本不匹配" | — |

原则：**一个错误码配一个真实补救，没有补救就不编**。未知错误码也会说人话（"播放出现问题" + 原始信息），而不是甩一个代码。

## 测试里抓到的一个自身设计问题

`describeSwitches` 最初把 `key` 覆盖成了语义名（`audible`），于是"开关组合"和"它的含义"混成一个字段。测试断言 `key === 'on-on'` 时暴露出来。现在 `key` 是组合本身、`name` 是含义，两者不再互相顶替。

另一条测试直接**用真实 Core 驱动面板**（`requestTrack` → 读快照 → `setHumanPlayback false` → `setMode off`），断言面板显示的开关与模式跟核心一致——**如果核心的 settings 形状变了，这条会失败而不是悄悄漂移**。
