# N10 歌曲反馈与推荐偏好重置

2026-10-03 用户要求：不喜欢的推荐可降低权重，喜欢的歌曲可点赞，并能重置沉淀的推荐偏好。实现沿用本地规则与既有认证命令，不新增模型请求或平台账号写操作。

## 社区参考与取舍

检索日期 2026-10-03，仅借鉴交互语义，未复制代码、素材或安装依赖：

- [ListenBrainz Feedback JSON](https://listenbrainz.readthedocs.io/en/latest/users/feedback-json.html) 明确定义 `1` 喜欢、`-1` 不喜欢、`0` 撤销反馈；其 [Feedback API](https://listenbrainz.readthedocs.io/en/latest/users/api/recordings.html) 按歌曲身份持久保存用户反馈。
- [Navidrome](https://github.com/navidrome/navidrome) 与 [OpenSubsonic star](https://opensubsonic.netlify.app/docs/endpoints/star/) / [unstar](https://opensubsonic.netlify.app/docs/endpoints/unstar/) 提供可取消的歌曲收藏；收藏动作与播放动作分开。

FishFM 采用“喜欢 / 少推荐 / 撤销”的独立反馈层。没有把社区的收藏接口当作推荐算法，也没有接入这些远程服务。重置与恢复点按本项目的历史/成长/账本边界自行实现。

## 行为与参数

播放器下方新增“喜欢”“少推荐”。重复点击同一项撤销，另一项替换原反馈；以平台 ID 定位歌曲，并携带播放实例，晚到操作不能写到下一首。反馈仅影响肥鱼电台，不同步网易云“我喜欢”，也不自动换歌或更改暂停/静音。

schema v9 的 `user_track_feedback` 与输入环境、Agent affinity 分开。local-v3 在熟悉池/陌生池评分末尾加入喜欢 `+0.25` 或少推荐 `-0.75`。这是首版有界参数；少推荐不等于永久禁播，只有候选很少时仍可能选到。禁播、不可播与冷却过滤仍优先。少推荐歌曲不再作为相似推荐种子；喜欢的歌曲进入熟悉候选/种子，不制造有效收听，也不写输入环境。真实推荐质量仍需用户长期体验。

“推荐反馈 → 偏好重置与恢复”提供确认/取消，默认只重置成长偏好并按当前输入曲库与原种子重新初始化；可勾选一起清除手动反馈。账号、输入曲库、播放历史、禁播、音乐模式与 token 账本保留，旧模型总结移除，之后仍按预算/冷却与用户授权生成。模型总结进行中拒绝重置，避免晚到结果恢复旧总结。

重置前在同一 SQLite 事务保存一份恢复点，支持撤销最近一次重置；再次重置替换恢复点。撤销恢复 affinity、Session 成长上限和旧总结；如果清除了反馈，也恢复原反馈，但重置之后的新反馈（含撤销为 0）优先。撤销会恢复旧权重，覆盖重置后积累的成长。备份与命令去重记录同事务提交。

成长设置重置边界：重置前开始的播放、当前播放实例与缺少开始时间的旧作业不会重新成长，但历史仍正常记录；新开始的有效收听继续积累。画像的最近变化过滤重置之前的记录；历史统计继续如实保留其窗口范围。
