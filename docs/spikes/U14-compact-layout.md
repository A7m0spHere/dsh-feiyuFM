# U14：主面板与设置紧凑布局

2026-10-07。按用户要求查看现有界面并做紧凑优化，沿用 PHL 配色、组件与原角色素材。实际调整客户端布局与说明层级，没有改 Core、音频、平台或模型调用。

## 布局调整

- 顶部播放器把播放/下一首/今天停止与喜欢/少推荐合并到同一操作区；窄窗口自然换行。来源移到时间行，普通反馈说明收入选歌依据；选择后的反馈与异常提示仍常显。「大肥鱼说」保留完整回复，用紧凑行展示。
- 四个模式改为一行四项，保留选中态、键盘和完整无障碍描述。说明可通过原按钮描述/悬停查看；彩蛋小开关继续无文字、无悬停说明。
- 主面板仍左侧画像、右侧听歌设置，右列由 320px 收到 280px；不足 740px 时保持单列。设置席位仍设置在前、画像在后，DOM 与视觉顺序一致。
- 收紧卡片内外间距、设置行、曲库行和装饰图片；320px 页头不再挤压标题。没有用全局缩小字号来代替布局调整，按钮保留至少 32px 高，switch/焦点语义保留。
- 推荐规则与完整推荐曲目使用原生 `details` 默认收起；可播放数量、参考数量、生成按钮、错误和今日/累计 token 常显。输入曲库、预算、自动更新与重置入口保留，展开状态可随轮询保持。
- 悬浮条只收紧内边距、行距和角色尺寸，暂停/下一首/菜单/隐藏/重新显示及弹出方向保留。
