# U22 工作区 ASCII 水平流体频谱

更新：2026-10-30。基于 `2fcbdd975328309873c90efe96a3c9fa427fcac3`，在 `feat/ascii-spectrum-bars` 修正绘制方向，不合并 main。状态、测试数量与下一步只维护在 [PROJECT_PLAN](../PROJECT_PLAN.md)。

## 坐标与视觉契约

频谱位于 Sidebar 右边界与正文左侧之间的背景留白。容器位置保持原有逻辑，频段沿 Y 轴从上到下排列，能量控制 X 轴的条长：

| 坐标 | 当前含义 |
|---|---|
| 左侧基线 | 字符网格第 0 列，贴合背景容器最左侧 |
| Y 轴 | 频段的固定纵向位置，低频在上、高频在下 |
| X 轴 | 条体从左向右的长度；能量下降时右端向左回缩 |
| 条长 | `normalizedEnergy * columns`；零能量不填充条体 |
| 流体位移 | 轻微上下位移，左端为零，沿条长向右平滑增加 |

2026-10-29 的底部锚定竖柱方案已被本轮坐标契约取代。旧截图、计时与原生样本属于历史证据，不作为本轮方向验收；原文可用 `git show 2fcbdd9:docs/spikes/U22-ascii-spectrum-backdrop.md` 查看。

## 挂载与几何

继续使用 `shell.overlay` 中的 `fishfm.spectrum` 与 `[data-conversation-content]`。左侧宽度手柄／`[data-composer-card]` 推导留白，缺失时退回宿主宽度公式。容器宽度为 `min(160px, gutter-12px)`，不足 72px 隐藏，高度使用工作区可用高度。不依赖固定屏幕坐标或宿主哈希类名。

根层透明、无底色／边框／阴影、`pointer-events:none`、`aria-hidden`，仅一个 Canvas。不修改 Sidebar、正文和输入框布局。`data-columns`／`data-rows` 只提供当前真实网格尺寸供验收读取，不参与动画控制。

## 水平条场与 Canvas

- `renderSpectrumScene` 输出 `{grid, offsets, bars, baseline}`，`baseline=0`。每条记录 `center/startRow/endRow/length/end/value/peak`，不再生成竖柱的 `height/top/maxHeight`。
- 条数为 `min(输入频段数, 32, floor((rows-2)/3))`；每条两行，至少空一行，上下留安全行。当前模拟输入 28 个频段，960px 工作区的 80 行网格显示 26 条；更高或更矮时随高度适配，宽度不决定条数。
- 字符从第 0 列连续向右填充。主体较密、右端渐疏，内部由连续低频函数缓慢流动；峰值标记在右端前方独立保持并向左回落。不是横向浪线，也不是重复 `||||`／`====`。
- `offsets` 表示 Y 方向的亚字符位移；`drawSpectrumScene` 的 X 坐标始终为 `(x+.5)*cellWidth`，Y 坐标为 `(y+.5+offset)*cellHeight`。不旋转 Canvas、字符或宿主容器。
- 延续实际字体墨量校准、DPR 上限 2 和局部 Canvas 绘字，不引入 Three.js、WebGL、远程字体或新依赖。渲染不逐帧读取像素。

浅色／深色播放透明度仍为 `.60`／`.48`，暂停 `.26`／`.24`；蓝色与右向渐隐保持上一轮配置，72% 后才开始柔化，90% 仍有 65% 遮罩强度。

## 时钟、状态与资源

保留 `createSpectrumClock`／`createSpectrumDriver` 的 1/60s 积分与 250ms 追赶上限，完整档目标 24fps、轻量档 240ms、关闭档静态。播放状态、进度和曲目种子走 ref，快照轮询与 resize 不重启动画。已开始的播放可跨 `resolving` 继承活动状态，首次准备不提前启动，暂停／idle／错误／断连清除继承状态。

静态档跟随宿主主题重绘；系统减少动态的实时变化仍监听并清理。`ResizeObserver`、主题观察者、窗口监听、rAF 与定时器的原有清理机制保留；目标消失或留白过窄时不推进画面和彩蛋。

## 鲸鱼与横条的合成

保留 `spectrum-whale.mjs` 的四姿态、五阶段导演、冷却和取消机制，许可见 [第三方声明](../../THIRD_PARTY_NOTICES.md)。没有独立浮层或动画时钟。

`spectrumWhaleLine` 从纵向频段中选定一个局部活动带，不再依赖条长或竖柱顶部。鲸鱼从该带的条端附近浮出；事件首次合成保存行／列比例，避免被条端伸缩拖动，resize 按比例约束到当前网格。潜伏与出入时只局部增加附近条长，结束后由正常频段自然恢复。

`composeField` 先生成水平条场，再将鲸鱼写入同一字符矩阵，清除实体内部原字符并将对应上下位移归零，最后由一个 Canvas 绘制。简短水花仍限定在身侧和少量格子。暂停、停止、减少／关闭动态、隐藏、面板打开和过窄时取消。

## 边界

当前仍为播放状态驱动的模拟频段，不是歌曲真实 FFT。`step(dt,{frequencyBands})` 的归一化替换口保留，没有新增宿主协议、RPC、媒体 URL、PCM、模型事实或数据库字段。

本轮实际工作区证据属于隔离 DSH Web；不补记原生 Desktop、macOS、多显示器／DPI 或长时间资源稳定性通过。历史按镜像名误杀的事故边界继续遵守，只清理本次启动的进程和临时页。前台完整流畅度与用户主观观感仍待确认。
