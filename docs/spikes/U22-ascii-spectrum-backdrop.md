# U22 工作区 ASCII Fluid Spectrum

更新：2026-10-29。本轮在 `feat/ascii-spectrum-bars` 迭代，未合并 `main`。状态、测试基线与下一步只维护在 [PROJECT_PLAN](../PROJECT_PLAN.md)，用户行为见 [MVP §5](../MVP.md)。

## 审查与修订

此前实现的主体是 `renderSpectrumGrid` 中的多层横向浪脊循环：`~ / - \` 随透视铺开、深处挖孔、顶部另画峰值。它没有从底部填充的柱身。模拟目标又使用随频率固定衰减的基底，容易形成左高右低斜坡。浅色 `.17`／深色 `.32` 透明度叠加从 42% 开始的渐隐，让字符难以辨认。

本轮以用户提供的 ASCIIText 代码作视觉思路参考，自行实现连续亮度场，不复制 React/Three.js 源码，不引入依赖。此次柱群取代 2026-10-28 的横向海面方案；既有时钟、状态 ref、挂载与鲸鱼导演继续复用。旧版调查和事故原文可用 `git show e3c878f:docs/spikes/U22-ascii-spectrum-backdrop.md` 查看，旧海面截图和测试不能证明本轮视觉通过。

## 几何与层级

继续将 `fishfm.spectrum` 注册到 `shell.overlay`，使用 `[data-conversation-content]` 测量工作区；左侧宽度手柄／`[data-composer-card]` 推导留白，缺失时使用宿主宽度公式。背景宽度为 `min(160px, gutter-12px)`，不足 72px 隐藏，纵向占真实可用高度。没有固定屏幕坐标或宿主哈希类名，不改变侧栏、正文或输入框布局。

根层透明、无边框、无阴影、`pointer-events:none`、`aria-hidden`；仅有一个 Canvas。`ResizeObserver`、窗口 resize 和低频目标巡检保留。目标消失时不生成画面、不推进模拟或彩蛋；卸载清理观察者、rAF、定时器和主题监听。

## 亮度场与绘制

- `spectrum-bars.mjs` 输出 `renderSpectrumScene -> {grid, offsets, bars, baseline}`。列数决定能容纳的柱数，常规 160px 条带约五根柱；各柱宽约三格，保留独立空隙。底部统一锚定最后一行，不生成倒影或横向浪脊。
- 每根柱的高度由所采样频段决定；占用范围、柱顶距离、横向边缘、局部能量和连续慢波共同生成亮度。主体密、顶部疏、内部缓慢流动，非随机逐格换字。
- `spectrum-canvas.mjs` 初始化时用实际等宽字体测量候选字形墨量并排序；只在字体变化时重新测量。每帧按网格绘字，不逐帧读像素。DPR 上限 2，画布仅覆盖条带，不创建全屏 Canvas、WebGL 或 3D 场景。
- `spectrumBend` 以两组连续周期场产生小于半个字符的横向位移，底部恒为零、向柱顶平滑增加，相邻柱相关且不同步。Canvas 保留亚像素位移，避免纯 `<pre>` 整数列偏移的跳格；字符的纵向网格与轮廓不变。
- A/B 对照位于 `npm run preview:ui -- --react-root <React UMD 路径>` 的 `/spectrum-ab`：A 不扭曲，B 轻微扭曲。两者共用生产 CSS、同一引擎／时钟、同一输入和 160×760px 尺寸，可选 12/24fps；统计十帧预热后的分项均值／p95，不新增生产调节项。

## 音乐动态与状态

模拟频段不再有固定衰减斜坡；种子化目标、邻段共享的连续能量包与独立局部峰谷叠加。低频响应较厚重，高频更敏捷；快起慢落、峰值短暂保持后重力回落。柱高是主运动，弯曲与纹理是次运动。

`createSpectrumClock`／`createSpectrumDriver` 保留 1/60s 固定积分与 250ms 追赶上限。完整档以 24fps 采样，轻量档 240ms，关闭档只画静态基线。绘制频率不改变模拟速度；播放进度、曲目种子和活动状态通过 ref 更新，不因快照轮询或 resize 重启动画。系统减少动态的实时变化也会更新档位。

原生取证暴露换曲窗口的视觉问题：`presentation.active` 在 `resolving` 时为 false，而鲸鱼按更宽的 listening 判据继续，柱体退到底部后鲸鱼会悬空。本轮只在已经开始过播放且仍 listening 时继承背景能量，首次准备不提前启动；暂停、idle、错误或断连立即清除继承状态。它不改变播放服务或界面文案。

Canvas 静态档观察 HTML/body 的主题属性：主题切换重绘字色，避免只切 CSS 透明度却保留旧像素。浅色播放 `.60`、深色 `.48`；暂停 `.26`／`.24`。右向渐隐从 72% 开始、90% 仍保留 65%，正文方向最后淡出，保留大部分柱群。

## 鲸鱼适配

保留 dsh-TUI／dsh-ui-whale 的四姿态母版、五阶段导演、首次等待与冷却，许可仍见 [第三方声明](../../THIRD_PARTY_NOTICES.md)。没有另建动画时钟。

潜伏时局部柱短暂隆起，出水／下潜带来局部扰动；鲸鱼水位从附近柱顶推导，一次事件保持相对水位稳定，resize 按比例重画。`composeField` 先生成柱群、再 `stampWhale` 改写同一网格与位移，最后一次绘制。鲸鱼每行实体轮廓内部的空白也擦除原字符，位移归零，避免柱体透过鲸鱼。水花只在两侧和少量离散格出现。

鲸鱼宽度限制为条带约 58%，事件中缩窗重新计算；缩放缓存用完整姿态内容作为键，修复不同姿态首行相同而误复用的问题。暂停、停止、关闭／减少动态、隐藏页面、打开全局面板或过窄时取消；恢复由正常柱群自然接续，不留下鲸鱼专属网格。

## 数据边界

Windows 音频仍由原生 WPF MediaPlayer 播放，UI 没有 PCM／FFT。当前是由播放状态、进度和曲目种子驱动的模拟频段，不能声称与歌曲真实高低频同步。

引擎 `step(dt, {frequencyBands})` 留下归一化频段替换口：非空数组沿频率位置采样、限于 0..1，并走相同包络与峰值链；缺省／空输入使用模拟器。该接口仅在本地引擎，未新增宿主协议、RPC 或媒体 URL 传递，没有修改推荐、数据库和播放架构。

## 本轮取证与复现

本机证据在忽略提交的 `work/u22-20261029/`。截图使用生产透明度；无强制不透明 CSS。A/B、Web 最终验收、原生阶段证据和性能 JSON 分开保存，详细结果与验收缺口见 PROJECT_PLAN。

原生阶段使用官方 DSH 0.2.1-rc.3：独立 DSH_HOME 与 Electron user-data-dir，官方 `dsh-desktop-host/lib/cli.js plugin --profile desktop add ... --offline` 安装源码链接；本地假 Provider＋生成的静音 WAV＋真实 WPF。通过官方 `dshWelcome.skip()` 的本次“稍后配置”入口进入工作区，没有复制日常账号或 key。浅色、宿主设置切换的深色、默认鲸鱼五阶段有原生截图；位置实测 x=280/y=80、145×742px，适配实际留白。它们属于本轮早期原生样本，后续修复按用户要求转到已有 Web profile 后台静默复验，不把最终 Web 结论补记为最终 Desktop 完整验收。

Web 阶段复用 `.tmp/whale-accept` 隔离 profile，`--no-open`，本地夹具，不调用真实模型。浏览器完成 launch URL→cookie 交换；控制命令走宿主认证 RPC，几何、主题、暂停、窄窗口、档位与生命周期分项验证。浏览器截图失败时换用隐藏 IAB 取证，仍来自同一隔离 Web 服务。最终鲸鱼五阶段在实际生产组件的预览 harness 以既有 eager 参数验证，跃出截图为 `final-whale-preview-breach.png`；最终 Web profile 默认冷却事件未在本轮观察窗内采到，不把预览标成真实宿主事件。

单元回归覆盖实际频段映射、底锚、密度层次、柱间留缝、位移连续性／边界、网格变化、时钟、鲸鱼遮挡／缩窗、状态继承、静态主题与系统减少动态的监听清理。全量测试、模块检查、构建与 debug smoke 按 PROJECT_PLAN 记录，不以旧横向浪线断言作为验收。

## 边界与待确认

用户 2026-10-29 要求后续使用已有 Web 端后台静默测试；不再打开原生窗口。日常 Desktop 不重载、不批量结束进程，只收尾本轮进程。此前按镜像名误杀的历史事故仍有效，本轮未沿用该清理方式。

真实 FFT、最终版本的完整原生 Desktop 组合、macOS、多显示器／不同 DPI 和长时间资源稳定性未补验；短样本性能不能替代长期结论。隐藏 IAB 会节流帧调度，且追赶上限会丢弃长间隔；`ascii-spectrum-ab.gif` 是后台连续截图样本，不用它宣称真实前台稳定 24fps。最终主观亮度、弯曲强度和鲸鱼辨识度仍待用户查看截图／动画确认，不以程序化测试替用户给出主观通过。
