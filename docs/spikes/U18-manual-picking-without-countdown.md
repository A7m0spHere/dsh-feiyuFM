# U18：手动找歌取消倒计时

日期：2026-10-09。用户提供“没有挑好的歌单”与“13:33 后可换”截图，要求取消 15 分钟倒计时。

## 改动

- 手动找歌/换批取消模型冷却，服务端按钮投影与预留事务使用同一规则；后台自动筛选继续验证 15 分钟冷却。
- 按钮在任务结束后恢复“找一批歌/换一批”；空筛选、失败和中断都不产生手动等待，仍受每日次数、真实账本与 token 预算限制。
- 前端删除分钟倒计时和每秒刷新，保留旧宿主等待提示、到期恢复与每日次数重置；预览成功后恢复可换批，重复提交模拟任务占用。
- 平台 1 分钟刷新节流与同批缓存复用保留，短时间重复点击可能复用已有结果；取消模型冷却不保证产生新歌曲。
- 全量检查发现已有 macOS 模拟播放路径仍写死 Windows 管道，以及数据库位置测试使用 Windows 绝对路径。模拟播放复用生产 `pipePath` 并清理崩溃遗留 socket；数据库测试改用当前平台绝对路径。均不改变真实音频后端。

## 验证与边界

- 推荐回归覆盖一批成功后在 15 分钟内再次换批、空筛选后重试、跨窗口任务占用、预算/每日次数、后台冷却、中断计费与暂停保持。
- 客户端 bundle 测试覆盖按钮无分钟倒计时、当前宿主可换批、旧宿主普通等待和失败技术详情，已有歌曲仍可点播。
- 模拟播放真实子进程的握手、曲终、暂停、断连恢复、崩溃重建与退出测试通过；不是平台音频验收。
- 全量测试/模块检查/构建结果统一记录于 [PROJECT_PLAN](../PROJECT_PLAN.md)；`npm run audit:acceptance` 与 `git diff --check` 通过。
- 本机 `desktop` profile 的插件符号链接已核对指向本仓库，客户端 bundle 已同步。DSH 后端缓存模块，需要完整退出并重开才加载新规则；本轮未重启生产或调用真实模型，npm 未更新，截图的真实推荐质量问题仍需重载后复验。
