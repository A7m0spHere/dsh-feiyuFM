- `scripts/cutout-whale-pot.py` 为该附件的专用资产构建脚本，检查输入 hash，使用 [OpenCV GrabCut](https://docs.opencv.org/4.13.0/d8/d83/tutorial_py_grabcut.html) 与天空/草地、深蓝角色前景标记；对 7 帧浅色侧鳍增加前景种子，并恢复轮廓内被误分的浅色细节。
- PNG 前景直接来自原帧 RGB，只改透明蒙版，不重新绘制、旋转、逐帧缩放或移动角色。所有帧采用同一个整体裁切 `(0,36,320,396)`，保留原始转身和起伏位置。GIF 使用共用调色板和一位透明度，编码涉及调色板量化。

- 静态图 `whale-pot-still.png` 来自原第 16 帧的正面视角。
